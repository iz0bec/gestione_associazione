Come funziona

  1. Dalla pagina della lista, Esporta in Excel.
  2. Si modifica il file anche senza collegamento: impostazioni nel foglio «Lista», persone ed enti nel foglio «Persone» (istruzioni nel foglio «Istruzioni»).
  3. Si importa qui: il codice della lista nel file dice quale aggiornare; senza codice si crea una lista nuova (o si aggiorna quella con lo stesso nome).

Le persone sono riconosciute per codice, codice fiscale o email. L'importazione sostituisce le persone scelte e le impostazioni della lista: chi non è più nel file viene tolto.
