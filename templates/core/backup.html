Come funziona

  • Un backup contiene tutto: il database e i file caricati (documenti protocollati, foto, loghi, moduli firmati).
  • {% if automatico %}Ogni notte, dalle {{ ora }}:00, viene creato un backup automatico.{% else %}Il backup automatico notturno è disattivato.{% endif %} Degli automatici si conserva l'ultimo di ciascuno degli ultimi {{ politica.giornalieri }} giorni, {{ politica.settimanali }} settimane e {{ politica.mensili }} mesi.
  • Degli altri backup (manuali, caricati, prima di un ripristino o di un aggiornamento) {% if politica.altri %}si conservano gli ultimi {{ politica.altri }}{% else %}non se ne elimina nessuno{% endif %}. L'ultimo di ciascun gruppo non viene mai eliminato da solo.
  • Con si esclude un backup dalla rotazione (es. quello di fine anno o prima di una migrazione): resta finché non lo si rimette in rotazione o lo si elimina, ma il suo spazio conta nel totale.
    • {% if politica.spazio_massimo %}
  • I backup non superano in tutto {{ politica.spazio_massimo|filesizeformat }}: oltre, si eliminano i più vecchi.
    • {% endif %}
  • Un backup non parte se lascerebbe sul disco meno di {{ politica.spazio_libero_minimo|filesizeformat }} liberi.
  • Prima di ogni ripristino viene salvato in automatico lo stato attuale.
  • Copiare i backup anche fuori dal server (scaricandoli o con una copia pianificata della cartella): un backup sullo stesso disco non protegge da un guasto del disco.
  • I backup contengono dati personali: conservarli in un luogo protetto.
